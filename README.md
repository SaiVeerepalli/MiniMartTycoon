# Mini Mart Tycoon

An original Android mini-mart tycoon prototype built with Kotlin + a bundled HTML5 canvas game.

## Gameplay
- Collect/produce goods
- Stock shelves
- Customers buy automatically
- Earn cash
- Build shelves, checkout and farm
- Level progression unlocks new products
- Pan and pinch/scroll to zoom the store
- Progress is saved locally

## Build
Open this repository in GitHub and use the included GitHub Actions workflow to build the debug APK.

## Important
This game is inspired by the *tycoon/shop-management genre* and by the gameplay loop of games such as My Mini Mart. It does not copy their characters, art, UI, names, or proprietary assets.

Ads use Google's official test IDs during development. Replace them only after creating your own AdMob app/ad units and before release.
